Calldata Decoder

Paste EVM transaction input data (0x…). The selector is looked up in public signature databases (openchain, 4byte), or you can paste your own ABI. Arguments are decoded, nested multicall / aggregate / Safe execTransaction / execute payloads are decoded recursively, and risky actions such as unlimited approve, setApprovalForAll and transferOwnership are flagged.

Optional ABI (JSON array or human-readable lines like function foo(uint256 a))
